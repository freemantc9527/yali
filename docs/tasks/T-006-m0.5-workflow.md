## 实现要点
- `workflows/templates/yali-quick-action.workflow/`：Info.plist（NSServices：public.image / Finder / runWorkflowAsService）+ document.wflow（Run Shell Script，inputMethod=1 传参）
- `install-workflows.sh`：解析 yali 路径（$YALI_BIN → command -v → target/{release, debug}）→ 渲染模板 → 安装 → `killall pbs`
- CLI：`compress --notify` 结束时 osascript 发一条聚合通知（标题「鸭梨」）
- 引擎解析兜底：PATH 缺失时查 `/opt/homebrew/bin`、`/usr/local/bin` 与 brew keg；brew 命令本身也用绝对路径兜底
