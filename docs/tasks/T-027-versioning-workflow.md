## 规范取舍

- KISS / YAGNI：沿用 `dev` / `main`，不增加常驻分支、提交钩子或自动发版工具。
- DRY：版本和 Git 交付规则集中于 VERSIONING，WORKFLOW 只提供入口；具体测试命令继续以 AGENTS 为准。
- 区分版本定位与实际发布，区分提交、推送、合入、标签与发布的授权。
