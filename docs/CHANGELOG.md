## 0.1.0-alpha

当前 alpha 版本包含：

- Finder 右键压缩和转 JPG 两条快速操作。
- Tauri 桌面工作台、批量队列、预设、设置、原图与产物对比。
- `yali` CLI，和桌面应用共用 Rust 内核与 Profile。
- 日常压缩、转 JPG、缩小尺寸和无损归档预设。
- 自包含 macOS App，处理运行时随 App 分发，不要求用户安装 Homebrew。
- 剪贴板监听、监视目录、菜单栏托盘和系统通知入口。

已知限制：原生交互仍有待人工验收项目，Windows 首轮编译已完成，图片运行时和真实桌面运行仍待验证，当前 App 使用 ad-hoc 签名。
